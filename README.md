# GPS AntiRadar

Личное некоммерческое приложение для Android 8–16 (compileSdk/targetSdk 36).
Оно показывает GPS-скорость, рисует объекты контроля поверх Яндекс-карты и
предупреждает о приближении к ним.

## Возможности

- Яндекс MapKit 4.42 Full и устойчивая собственная кластеризация объектов на карте;
- построение автомобильного маршрута от текущей GPS-позиции по долгому нажатию
  на карту; линия, расстояние и время отображаются на телефоне и в Android Auto;
- поиск конечного адреса через SearchKit с выбором подходящего результата;
- окраска сегментов маршрута по актуальной дорожной обстановке: свободно,
  небольшое или сильное затруднение, пробка и перекрытие;
- плавное дифференциальное обновление маркеров в области карты с 20% буфером;
- компактные кнопки карты, плавное изменение масштаба и анимированный переход к GPS-точке;
- жёлтая стрелка текущего положения, поворачивающаяся по актуальному GPS-курсу;
- отключаемый автоповорот карты по ходу движения на телефоне и в Android Auto;
- автоматическое сопровождение GPS-точки при движении с паузой на 7 секунд после ручного перемещения или зума;
- полноэкранный режим без системной строки состояния;
- масштаб интерфейса настраивается от 100% до 200%, а карты — от 100% до 500%; оба слайдера имеют шаг 10% и значение по умолчанию 100%;
- настройка прозрачности плашки скорости с сохранением выбранного значения;
- автоматический запуск фонового GPS-мониторинга при открытии приложения;
- скорость только по GPS без ложных скачков между GPS и сетевыми координатами;
- голосовые предупреждения по расстоянию и направлению движения;
- типы RadarBase, включая камеры наблюдения, муляжи, мобильные камеры,
  контроль средней скорости, стоп-линии, полосы и обочины;
- оригинальные Vector Drawable для известных типов RadarBase размером 42 dp,
  с резервной иконкой типа 0, кэшированием и поворотом по направлению камеры;
- зоны из полей RadarBase `dir`, `dirType`, `distance`, `revDistance` и `angle`;
- восстановление обфусцированных координат по `meta.build`; если значение
  `build` не удалось прочитать, поправка координат намеренно не применяется;
- актуальное ограничение для легкового автомобиля из `speedControls`, включая
  временные интервалы и раздельные ограничения по типу транспорта;
- хинт с данными объекта по нажатию на значок;
- локальная SQLite-база — координаты пользователя никуда не отправляются.
- пользовательские объекты: долгое нажатие на карту сохраняет точку в месте нажатия после
  выбора типа; параметры зоны редактируются из подсказки маркера,
  долгое нажатие на собственную точку позволяет перетащить её с сохранением новых координат;
  такие точки выделяются синей рамкой и не удаляются при обновлении RadarBase;

## База объектов RadarBase

База не входит в APK. При холодном запуске приложения российский файл
`main_extended.json` автоматически проверяется и при необходимости загружается
по HTTPS непосредственно с RadarBase. Повторная проверка использует
`ETag/Last-Modified` и не скачивает неизменившийся файл заново. Ручной запуск
проверки остаётся доступен через пункт **Обновить базу объектов** в меню.
Поддерживается потоковый формат RadarBase schema 3.x. Обновление транзакционное:
при повреждённом или несовместимом ответе прежняя рабочая база сохраняется. В
приложение импортируются все объекты из файла. Все объекты используют единый
зональный алгоритм оповещений. В настройках карты можно показывать зоны только
для камер и объектов контроля либо для всех типов объектов.

Использование данных предполагается только личное и некоммерческое. Перед любым
распространением приложения или данных нужно отдельно проверить актуальные
условия RadarBase и получить необходимые разрешения.

## Ключ Яндекс MapKit

Ключ **MapKit Mobile SDK** для пакета `ru.gpsantiradar.app` встроен в приложение.
Пользовательский ввод ключа не требуется.

Для построения маршрута сделайте долгое нажатие на точку карты и выберите
**Построить маршрут сюда**. Новый маршрут заменяет предыдущий; удалить его можно
через пункт **Сбросить маршрут** в меню карты. Функция использует DrivingRouter
MapKit и не включает пошаговое голосовое ведение NaviKit.

Построение по адресу доступно через **Карта → Маршрут по адресу**. После ввода
можно выбрать подходящий найденный адрес. Долгое нажатие непосредственно на линию
готового маршрута заменяет действие построения на **Удалить маршрут**. Свободные
участки, затруднения, пробки и перекрытия показываются разными цветами по данным
`JamSegment` MapKit; информация обновляется, пока маршрут активен.

## Сборка

На Windows с Android SDK 36 и JDK 21:

```powershell
.\build.ps1
.\test.ps1 -RadarBaseFile .\main_extended.json
```

Если SDK расположен нестандартно:

```powershell
.\build.ps1 -Sdk "D:\Android\Sdk"
```

В каталоге `outputs` появляются отдельные APK для `arm64-v8a`, `armeabi-v7a`,
`x86` и `x86_64`. Номер версии входит в имя каждого файла. Каждый APK содержит
нативные библиотеки только своей архитектуры, подписан локальным отладочным
ключом и предназначен для ручной установки. Для большинства современных
телефонов подходит `GPS-AntiRadar-<версия>-arm64-v8a.apk`.

## Android Auto

Приложение зарегистрировано как навигационное Android Auto. После подключения
телефона к совместимой головной системе откройте GPS AntiRadar из списка
приложений Android Auto. Экран движения выводит ту же карту MapKit, маршрут, объекты
RadarBase, скорость и текущий объект; меню позволяет обновить базу, изменить
параметры оповещений, открыть сведения о программе или
завершить сеанс.

Если MapKit не удалось инициализировать, Android Auto запускает антирадар и
звуковые предупреждения без карты и предлагает перезапустить приложение.

Телефонный экран и Android Auto используют один `TrackingService`: он получает
GPS-координаты, выбирает объекты, ведёт состояние зон и воспроизводит звуковые
оповещения. Экран Android Auto получает только его снимки состояния, поэтому
параллельный механизм оповещений не запускается. При закрытии телефонного или
автомобильного интерфейса общий сервис продолжает работать, пока его не остановит
явное действие выхода или система.

Для проверки без автомобиля используется Android Auto Desktop Head Unit (DHU).
DHU не входит в репозиторий. Воспроизводимый порядок запуска:

1. Установите DHU через Android Studio SDK Manager и подключите телефон по USB.
2. Откройте настройки Android Auto на телефоне, включите режим разработчика
   Android Auto, затем в настройках разработчика включите «Неизвестные источники».
3. Там же запустите сервер головного устройства.
4. В PowerShell из Android SDK настройте перенаправление порта:

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb forward tcp:5277 tcp:5277
```

5. Запустите DHU:

```powershell
$dhu = "$env:LOCALAPPDATA\Android\Sdk\extras\google\auto\desktop-head-unit.exe"
& $dhu
```

Разрешение на геолокацию требуется так же, как при запуске на телефоне.

## Безопасность

Это вспомогательный водительский инструмент, а не официальный источник дорожной
информации. Объекты могут изменяться быстрее обновления базы. Не работайте с
экраном во время движения и всегда соблюдайте знаки и правила дорожного движения.
