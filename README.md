# GPS AntiRadar

Личное некоммерческое приложение для Android 8–16 (compileSdk/targetSdk 36).
Оно показывает GPS-скорость, рисует объекты контроля поверх Яндекс-карты и
предупреждает о приближении к ним.

## Возможности

- Яндекс MapKit 4.42 Lite и устойчивая собственная кластеризация объектов на карте;
- плавное дифференциальное обновление маркеров в области карты с 20% буфером;
- компактные кнопки карты, плавное изменение масштаба и анимированный переход к GPS-точке;
- автоматическое сопровождение GPS-точки при движении с паузой на 7 секунд после ручного перемещения или зума;
- полноэкранный режим без системной строки состояния;
- настройка прозрачности плашки скорости с сохранением выбранного значения;
- автоматический запуск фонового GPS-мониторинга при открытии приложения;
- скорость только по GPS без ложных скачков между GPS и сетевыми координатами;
- голосовые предупреждения по расстоянию и направлению движения;
- типы RadarBase, включая камеры наблюдения, муляжи, мобильные камеры,
  контроль средней скорости, стоп-линии, полосы и обочины;
- оригинальные Vector Drawable для известных типов RadarBase размером 42 dp,
  с резервной иконкой типа 0, кэшированием и поворотом по направлению камеры;
- зоны из полей RadarBase `dir`, `dirType`, `distance`, `revDistance` и `angle`;
- восстановление обфусцированных координат по `meta.build`; если значение
  `build` не удалось прочитать, поправка координат намеренно не применяется;
- актуальное ограничение для легкового автомобиля из `speedControls`, включая
  временные интервалы и раздельные ограничения по типу транспорта;
- хинт с данными объекта по нажатию на значок;
- локальная SQLite-база — координаты пользователя никуда не отправляются.

## База объектов RadarBase

База не входит в APK. При холодном запуске приложения российский файл
`main_extended.json` автоматически проверяется и при необходимости загружается
по HTTPS непосредственно с RadarBase. Повторная проверка использует
`ETag/Last-Modified` и не скачивает неизменившийся файл заново. Ручной запуск
проверки остаётся доступен через пункт **Обновить базу объектов** в меню.
Поддерживается потоковый формат RadarBase schema 3.x. Обновление транзакционное:
при повреждённом или несовместимом ответе прежняя рабочая база сохраняется. В
приложение импортируются все объекты из файла. Камеры и объекты дорожного
контроля используют настраиваемую дистанцию и двухэтапное предупреждение. Для
дорожных объектов сектора на карте не строятся: они предупреждают один раз на
индивидуальной дистанции, указанной RadarBase, и только во время движения.

Использование данных предполагается только личное и некоммерческое. Перед любым
распространением приложения или данных нужно отдельно проверить актуальные
условия RadarBase и получить необходимые разрешения.

## Ключ Яндекс MapKit

Получите ключ **MapKit Mobile SDK** в
[кабинете разработчика Яндекса](https://developer.tech.yandex.ru/) для пакета
`ru.gpsantiradar.app`. Введите или смените ключ через меню приложения. Ключ
хранится только на телефоне.

Для сборки с ключом создайте `local.properties` рядом с `build.gradle`:

```properties
MAPKIT_API_KEY=ваш_ключ
```

Ключ не включается в архив исходников.

## Сборка

На Windows с Android SDK 36 и JDK 21:

```powershell
.\build.ps1
.\test.ps1 -RadarBaseFile .\main_extended.json
```

Если SDK расположен нестандартно:

```powershell
.\build.ps1 -Sdk "D:\Android\Sdk"
```

Готовый APK появляется в `outputs/GPS-AntiRadar.apk`. Он подписан локальным
отладочным ключом и предназначен для ручной установки.

## Безопасность

Это вспомогательный водительский инструмент, а не официальный источник дорожной
информации. Объекты могут изменяться быстрее обновления базы. Не работайте с
экраном во время движения и всегда соблюдайте знаки и правила дорожного движения.
